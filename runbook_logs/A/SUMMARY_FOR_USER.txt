LIMITS TO STATE
- No external network access: all HuggingFace models run strictly offline via local cached weights (HF_HUB_OFFLINE=1).
- Synthetic data only: evaluated solely on synthetic cases; no real personally identifiable information (PII) is processed or stored.
- Single-node deployment: file-backed concurrency controls (case_lock) and atomic filesystem persistence designed for single-host runtime.

DEVIATIONS
- Runtime file layout: Settings defines explicit properties users_path (runtime/users.json), secret_path (runtime/secret.key), and audit_path (runtime/audit.log) to consolidate runtime paths.
- Route aliases: retained /api/cases/{case_id}/files/cdr and /api/cases/{case_id}/files/bank alongside /cdr and /bank endpoints.
- User creation utility: refactored scripts/create_user.py to expose callable helper create_user(settings, username, role, password) while retaining command-line flags (--username/-u, --role/-r, getpass).
