### 3. SPECIFIC QUESTIONS AND ANSWERS

Question (a): does case_graph.builder.build_case_graph find analysis files only by the pattern FIR_*.analysis.json?
Answer (a): No. case_graph.builder._collect_fir_files matches all files ending with `*.analysis.json` (sorted(fir_dir.glob('*.analysis.json'))), and falls back to all `*.json` files if no `*.analysis.json` files exist. It does NOT require or restrict to the `FIR_` prefix.

Question (b): which function computes financial control per person?
Answer (b): `case_analytics.projection.build_person_projection(graph_data)` computes normalized financial control (`norm_financial_control`) and raw financial control in paise (`raw_financial_paise`) per person. `case_analytics.projection.compute_projection_scores(graph_data)` wraps this computation along with projection structural metrics.

Question (c): which function turns CDR rows into the call-layer person graph?
Answer (c): `case_detectors.cut_calls.call_layer_graph(cdr_rows, owners)` turns CDR rows and device ownership mappings into an undirected call-layer graph containing only PERSON nodes.

Question (d): what exact exception classes does the extractor raise for empty, too long and no-entity text?
Answer (d):
  - Empty text: `ai_pipeline.pipeline.EmptyText` (doc: Raised when input text is not a string, empty, or whitespace-only.)
  - Too long text: `ai_pipeline.pipeline.TextTooLong` (doc: Raised when input text exceeds MAX_CHARS.)
  - Zero entities: `ai_pipeline.pipeline.NoEntitiesFound` (doc: Raised when pipeline processing yields zero entities.)
